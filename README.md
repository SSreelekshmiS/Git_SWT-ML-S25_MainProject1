## Demo Web Shop - Manual and Automation Testing 
1. Project Overview
 
	This project focuses on manual and automating testing of the **Demo Web Shop application** which is 	an e-commerce application.
	Automation has been done using using Selenium WebDriver with Java and it follows the Page Object 	Model (POM) pattern which uses TestNG for test execution and Apache POI for reading test data 	from 	Excel files.

	Application URL: https://demowebshop.tricentis.com/


2. Technologies Used

	- Programming Language : Java
	- Automation Tool : Selenium WebDriver
	- Test Framework : TestNG
	- Build Tool : Maven
	- Design Pattern : Page Object Model (POM)
	- Test Data Management : Excel (Apache POI)
	- Browser : Google Chrome
	- IDE : Eclipse

3. Modules Covered

	The project covers the following application modules:
	- New Customer Registration
	- Existing Customer Login
 	- Customer Logout
	- End-to-End Shopping Workflow
		- Customer Registration-> Login -> Product Search -> Add Product to Cart -> Cart 	verification -> Billing and Payment details addition -> Checkout process


4. Manual Testing Deliverables

	- Feature Report
	- Test Plan
	- Test Scenarios
	- Test Cases
	- Requirements Traceability Matrix (RTM)
	- Bug Report
	- Test Execution Summary
	- Test Summary Report

5. Automation Testing Deliverables

	- Automation Test Scripts
	- Automation Framework
	- Test Data Excel File
	- End-to-End Test Script
	- TestNG Execution Reports
	- Automation Execution Results

 6. Conclusion

	With the above-mentioned criterias, the application was tested and verifed its functionality, 		usability, user interface and ensured the end-end shopping process completion for the Demo 		Web Shop application.
